# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

This project is pinned to SDK 54 (not the latest) because the Expo Go client installed on the
target test device only supports up to SDK 54. Do not upgrade the `expo` package without checking
that Expo Go on the device has also been updated to a version that supports the newer SDK.
